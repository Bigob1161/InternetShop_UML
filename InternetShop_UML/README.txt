Проект UML Designer «Интернет-магазин. Доставка товаров»

Как открыть:
1. UML Designer → File → Import → General → Existing Projects into Workspace.
2. Select root directory → выбрать папку InternetShop_UML → Finish.
3. В Model Explorer раскрыть representations.aird → Representations per category
   (или раскрыть модели и дважды щёлкнуть по нужной диаграмме).

Файлы:
- model.uml   – ваша модель вариантов использования (без изменений);
- design.uml  – классы, компоненты, развёртывание, деятельность, состояния, последовательности;
- representations.aird – все диаграммы (36 шт.).

Диаграммы:
- Диаграмма вариантов использования (ваша, без изменений);
- Диаграмма классов (композиция «Заказ» – «Позиция заказа», оплата заказа);
- Диаграмма компонентов, Диаграмма развёртывания;
- 10 диаграмм деятельности (включая общую с оплатой);
- Диаграмма состояний объекта «Заказ» (с состоянием «Оплачен»);
- 22 диаграммы последовательности.

Важно:
- В UML Designer нет фрагментов alt/opt, поэтому каждая альтернатива показана
  отдельной диаграммой последовательности («основной поток» и «альтернатива [...]»).
- Диаграммы последовательности заполняются автоматически при открытии.
  Если какая-то диаграмма открылась пустой или «съехала» – нажмите F5 (Refresh),
  затем правой кнопкой по фону → Arrange All, и сохраните (Ctrl+S / Cmd+S).
